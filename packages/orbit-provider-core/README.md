# Orbit Provider Core

The zero-dependency provider transport shared by Orbit CLI and Orbit Engine.

It contains fixed provider profiles, request and response conversion, model discovery, retries, and reasoning-state replay. Credentials, OAuth, billing, UI, tools, and skills are supplied by the host application and are not part of this package.

See the [Orbit CLI repository](https://github.com/soda-game-org/orbit-cli) for the public source and security policy.
