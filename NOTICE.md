# Boundary notice

This repository contains the open Orbit CLI and its loopback Web CLI only.

It intentionally excludes the closed-source Orbit Engine desktop application, internal service implementation, production deployment configuration, private prompts, private game-template skills, internal evaluation corpora and proprietary release/packaging procedures.

Official Orbit mode calls a separately operated authenticated API. Specialized official game templates remain server-side. BYOK mode uses the generic public skill included in this repository.
